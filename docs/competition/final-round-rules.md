📢 본선 문제 및 운영 안내
본선 참가팀은 아래 문제 구성, 데이터 구조, 채점 기준, 운영 규정 및 제출 방법을 반드시 확인한 후 대회를 진행해 주시기 바랍니다.

1. 문제 설명
본선 미션은 과거 태양 관측 데이터와 태양풍 속도를 활용하여 미래의 태양풍 속도를 예측하는 것입니다.

입력 구간: 과거 120시간(5일)

예측 구간: 미래 6시간 ~ 72시간

예측 간격: 6시간

최종 예측값: 샘플당 12개

● 입력 데이터
각 샘플에는 다음 데이터가 제공됩니다.

태양 관측 영상

총 20개 시점

6시간 간격

193Å / 211Å 두 종류의 이미지

태양풍 속도

총 20개 관측값

과거 5일간 6시간 간격

● 예측 목표
과거 데이터를 바탕으로 마지막 입력 시점 이후의

6h / 12h / 18h / … / 72h

태양풍 속도를 예측해야 합니다.

즉, 각 샘플마다 총 12개의 미래 태양풍 속도를 출력해야 합니다.

2. 데이터 구조 설명
전체 데이터는 Train / Validation / Test로 구분되어 제공됩니다.

Train: 9,607 samples

Test: 3,868 samples

● 주요 디렉터리 및 파일 구성

193Å 태양 관측 이미지가 저장되어 있습니다.

211/

211Å 태양 관측 이미지가 저장되어 있습니다.

각 target은 미래 6시간 ~ 72시간의 태양풍 속도를 의미합니다.

⚠️ Validation 데이터 사용 관련
Validation 데이터는 모델의 검증 용도로만 사용해야 하며, Train 데이터와 합쳐 최종 모델의 학습 데이터로 사용하는 것은 허용되지 않습니다.

따라서 다음과 같은 방식은 허용되지 않습니다.

Train + Validation 전체 데이터를 합쳐 최종 모델을 다시 학습한 후 Test 데이터를 예측하는 방식

Validation 데이터와 targets.csv는 모델 성능 검증, 모델 선택, 하이퍼파라미터 조정 등의 목적으로만 활용해 주시기 바랍니다.

이는 대회 종료 후 추가적인 성능 비교 및 결과 검증 과정에서도 동일한 Train / Validation / Test 구분을 유지하여 결과의 재현성과 참가 모델 간 공정한 비교가 가능하도록 하기 위함입니다.

4. 채점 기준 설명
전체 데이터셋은 다음과 같이 구성됩니다.

학습 데이터: 67%

검증 데이터: 8%

평가 데이터: 25%

Public: 12.5%

Private(Hidden): 12.5%

● 대회 진행 중 순위
대회 진행 중 공개되는 리더보드는 Public 데이터 기준으로 산출됩니다.

따라서 대회 중 확인되는 점수와 순위는 최종 순위가 아닙니다.

● 최종 순위
대회 종료 후 Public 데이터 + Private(Hidden) 데이터에 대한 평가 결과를 합산하여 최종 순위를 결정합니다.

● 메인 평가 지표: RMSE
본 대회의 주요 평가 지표는 RMSE(Root Mean Squared Error)입니다.

RMSE는 예측값과 실제값 사이의 오차를 제곱하여 평가하기 때문에 큰 오차에 더 큰 페널티가 부여됩니다.

따라서 단순히 평균적인 오차를 줄이는 것뿐만 아니라 특정 시점에서 매우 큰 예측 오차가 발생하지 않도록 하는 것도 중요합니다.

5. 운영 규정 및 유의사항
아래 사항을 위반하는 경우 부정행위로 간주되어 불이익을 받을 수 있으므로 반드시 확인해 주시기 바랍니다.

● 외부 데이터 사용 금지
대회에서 제공하는 데이터 이외의 외부 데이터는 사용할 수 없습니다.

● Pretrained Model 가중치 사용 금지
사전 학습된 Pretrained Model의 가중치를 사용하는 것은 허용되지 않습니다.

단, 기존에 알려진 모델의 아키텍처 또는 구현된 모델 구조를 활용하는 것은 가능합니다.

이 경우 Pretrained Weight를 불러오지 않고 Weight를 초기화한 상태에서 대회에서 제공된 데이터만을 이용하여 처음부터 학습해야 합니다.

● Validation 데이터의 학습 사용 금지
제공된 Validation 데이터는 검증 용도로만 사용해야 합니다.

Validation 데이터 및 Validation targets.csv를 Train 데이터와 합쳐 최종 모델을 학습하는 것은 허용되지 않습니다.

● Test Target 활용 금지
Test 데이터의 Target 정보를 추정·획득하여 학습 과정에 활용하거나 이에 준하는 Data Leakage 행위는 금지됩니다.

● 사람이 직접 생성한 예측 결과 제출 금지
모델을 활용하지 않고 사람이 직접 데이터를 처리하거나 판단하여 생성한 예측 결과를 제출하는 행위는 허용되지 않습니다.

● 제출 결과의 재현성
제출한 코드는 대회에서 제공하는 환경에서 정상적으로 실행 가능해야 합니다.

제출된 코드로 다시 추론했을 때의 결과와 실제 제출 결과의 성능이 크게 차이 나는 경우 불이익이 발생할 수 있습니다.

따라서 최종 제출 결과가 제출 코드와 모델을 통해 재현 가능하도록 구성해 주시기 바랍니다.
